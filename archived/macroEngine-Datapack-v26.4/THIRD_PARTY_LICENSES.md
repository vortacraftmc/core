## StringLib — CMDred

- Upstream: https://github.com/CMDred/StringLib
- License: MIT (verified against upstream `LICENSE`, copyright 2024 CMDred)
- Status: **no longer part of this pack.** Earlier releases shipped a string module
  (`core/internal/string/**`) that was derived from StringLib. That module has been
  deleted. Its replacement, `core/internal/text/**`, is macroEngine's own code (it is
  generated by `scripts/macroengine/gen_text.py` and uses a different algorithm: a
  one-character-at-a-time walk with no shared CharMap). The public wrappers in
  `core/lib/string/*` keep the same inputs and outputs, so existing callers do not change.
